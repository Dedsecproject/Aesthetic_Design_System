# Generate design specification

Transform the project brief into an implementation-ready UI design specification. Use the existing tokens and documented components first. Specify screen hierarchy, layout, responsive changes, interaction states, light/dark behavior, accessibility behavior, and semantic token mappings. Keep the aesthetic foundation stable while allowing project-specific content, navigation, density, and one solid accent. Do not introduce gradients, glows, neon, radiant treatments, glassmorphism, or arbitrary component variants.
