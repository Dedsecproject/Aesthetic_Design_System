# Tables

## Rules

- Use tables for comparable records, not for arbitrary page layout.
- Include a caption or accessible name, column headers, and a clear row action pattern.
- Align text left and numeric values right; use tabular numerals.
- Keep row height readable and provide hover/focus feedback without relying on color alone.
- At narrow widths, choose intentionally: allow controlled horizontal scroll with a visible cue, hide low-priority columns into a details view, or switch to stacked records.
- Include loading, empty, error, and pagination/sort/filter states where relevant.
- Never remove essential information solely because the viewport is small.
