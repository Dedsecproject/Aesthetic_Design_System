# Inputs

## Anatomy

Label, optional description, control, optional prefix/suffix, and validation message. The label remains visible; placeholder text is not a label.

## Rules

- Associate labels programmatically with controls and keep the hit area generous.
- Use the correct input type and autocomplete behavior.
- States: default, hover, focus-visible, filled, disabled, read-only, error, success.
- Use `border.focus` plus a visible focus ring. Do not remove outlines without an equivalent.
- Keep errors adjacent to the field, identify the problem, and explain the fix.
- Do not validate only through color. Use text and, where useful, an icon with an accessible name.
- Avoid putting multiple unrelated fields in one control.
