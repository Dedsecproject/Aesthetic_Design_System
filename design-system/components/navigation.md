# Navigation

## Rules

- Provide a stable orientation cue: product name, current section, and current location.
- Use one clearly indicated current item; do not rely on color alone.
- Desktop navigation may use a sidebar or top bar. On small screens, collapse into a labeled menu or bottom navigation only when destinations are few and high priority.
- Keep primary navigation separate from account, help, and destructive actions.
- Preserve browser back behavior and deep-linkable URLs.
- Use landmarks (`nav`, `main`, `header`) and logical heading order.
